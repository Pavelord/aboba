# Discord USB Audio Route

Экспериментальный Xposed/LSPatch-модуль для актуального Discord Android.

Он выполняется внутри процесса Discord и принудительно направляет коммуникационный звук в подключённую USB-гарнитуру. Модуль:

- перехватывает запросы Discord на встроенный динамик;
- заменяет динамик/разговорный динамик на `TYPE_USB_HEADSET` или `TYPE_USB_DEVICE`;
- повторно применяет USB-маршрут, если Discord его очищает;
- сам не включает `MODE_IN_COMMUNICATION`, поэтому не должен мешать установлению голосового соединения;
- показывает Toast и сохраняет последний статус в приложении модуля.

Поддерживаемые пакеты: `com.discord`, `com.discord.beta`, `com.discord.alpha`, `com.discord.canary`.

## Без root

Используйте совместимый с LSPatch менеджер, например MRVPatch Manager: разрешите сторонние модули, выберите этот APK как Xposed-модуль, пропатчите актуальный Discord APK и установите результат.

## С root

Установите APK модуля, включите его для Discord в LSPosed, принудительно остановите Discord и запустите снова.
