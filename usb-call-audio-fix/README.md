# USB Call Audio Fix

Экспериментальное Android-приложение для Android 12+.

Оно показывает список устройств, которые Android считает доступными для разговорного звука, и пытается назначить выбранную USB-гарнитуру через `AudioManager.setCommunicationDevice()`. Фоновый сервис повторяет назначение, если приложение звонка возвращает звук на динамик.

## Проверка

1. Подключить USB-гарнитуру.
2. Установить debug APK.
3. Нажать **Обновить список устройств**.
4. Выбрать USB-гарнитуру.
5. Нажать **Удерживать маршрут во время звонка**.
6. Войти в звонок Discord или Telegram.

Если USB-гарнитуры нет в списке, прошивка не считает её разговорным выходом и обычное приложение без root не сможет её назначить.
