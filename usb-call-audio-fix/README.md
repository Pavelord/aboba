# USB Call Audio Fix

Экспериментальное Android-приложение для Galaxy Tab A9+ и других устройств на Android 12+.

Оно показывает список устройств, которые Android считает доступными для разговорного звука, и пытается назначить выбранную USB-гарнитуру через `AudioManager.setCommunicationDevice()`. Фоновый сервис повторяет назначение, если Discord, Telegram или браузер возвращают звук на динамик.

## Как проверить

1. Подключить USB-гарнитуру Bloody через USB-A → USB-C OTG-переходник.
2. Установить debug APK.
3. Открыть приложение и нажать **Обновить список устройств**.
4. Выбрать USB-гарнитуру.
5. Нажать **Удерживать маршрут во время звонка**.
6. Не закрывая приложение, войти в звонок Discord или Telegram.
7. Если не помогло, вернуться в приложение и проверить, есть ли USB-гарнитура вообще в списке коммуникационных устройств.

## Что означает результат

- Если USB-гарнитура есть в списке и звук удалось удержать — проблема обходится программно.
- Если её нет в списке, прошивка считает USB-выход только мультимедийным; обычное приложение без root не сможет назначить его для звонков.
- Если она есть, но Discord/Telegram мгновенно перехватывает маршрут, Android может отдавать приоритет приложению, которое владеет режимом связи.

Приложение не записывает звук, не использует интернет и не требует root или USB-отладки.
